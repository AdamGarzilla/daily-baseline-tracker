# Daily Baseline Tracker PWA

This is an installable Progressive Web App.

## Important
A PWA must be served from HTTPS (or localhost). It cannot be installed directly from a `file://` preview.

## Fastest deployment options
1. Netlify Drop: drag this entire folder into Netlify Drop.
2. GitHub Pages: upload all files to a repository and enable Pages.
3. Vercel: import the folder/project and deploy.

## Install on iPhone
1. Open the deployed HTTPS address in Safari.
2. Tap Share.
3. Tap Add to Home Screen.
4. Open it from the new Home Screen icon.

## Install on Android/Desktop Chrome
Open the deployed address and tap the browser's Install option.

## Privacy
Entries are stored in the browser on the device using localStorage. Use Export backup regularly.
